# Baby Dukkan

Facebook পেজের ব্যবসার জন্য মোবাইল-বান্ধব ওয়েব অ্যাপ। অর্ডার নেওয়া, কাস্টমার ডাটাবেস, স্টক, খরচ আর লাভ-ক্ষতির হিসাব এক জায়গায়। সব তথ্য জমা থাকে আপনার নিজের **Google Sheet**-এ।

**অ্যাপ:** https://gonialsayed.github.io/baby-dukkan/

## যা যা করা যায়

- **নতুন অর্ডার:** মোবাইল নম্বর দিলেই পুরনো কাস্টমার চিনে ফেলে। প্রোডাক্টে ট্যাপ করে পিস বাড়ান-কমান, ডেলিভারি চার্জ বাছুন, সেভ করুন।
- **WhatsApp সামারি:** অর্ডার সেভ হলেই "Baby Dukkan ❤️ অর্ডার সামারি" তৈরি হয়ে যায়। এক ট্যাপে কপি বা কাস্টমারকে WhatsApp-এ পাঠান।
- **অর্ডার ট্র্যাকিং:** অপেক্ষায়, কনফার্ম, কুরিয়ারে, ডেলিভারড, রিটার্ন, বাতিল। কুরিয়ার আর কুরিয়ার খরচ লিখে রাখুন।
- **কাস্টমার ডাটাবেস:** কে কত টাকার কিনেছেন, শেষ কবে কিনেছেন। VIP, Repeat, New, Risky ট্যাগ নিজে থেকেই বসে। এক ট্যাপে কল বা WhatsApp।
- **হোম ড্যাশবোর্ড:** মাসের নিট লাভ, টাকা কোথায় গেল, রিটার্ন রেট, মাসভিত্তিক চার্ট, সবচেয়ে বেশি বিক্রি হওয়া প্রোডাক্ট।
- **প্রোডাক্ট ও স্টক, মাল কেনা, খরচ (৮ ক্যাটাগরি)।**
- **লাভ ক্যালকুলেটর:** ৮ ধরনের খরচ মিলিয়ে প্রতি পিসে আসল লাভ, লস না হওয়ার সর্বনিম্ন দাম আর টার্গেট লাভের দাম।
- ফোনের হোম স্ক্রিনে অ্যাপের মতো বসানো যায়।

## প্রথমবার সেটআপ (৫ মিনিট, একবারই)

অ্যাপটা আপনার Google Sheet-এ লিখতে ও পড়তে পারবে, এজন্য শিটে একটা ছোট কোড বসাতে হবে।

### ধাপ ১: কোড বসান

1. আপনার **Baby Dukkan Business Manager** Google Sheet খুলুন।
2. উপরের মেনু থেকে **Extensions > Apps Script**।
3. নতুন ট্যাবে এডিটর খুলবে। সেখানে যা লেখা আছে সব মুছে ফেলুন।
4. এই রিপোর ভেতরের [`apps-script/Code.gs`](apps-script/Code.gs) ফাইলটা খুলুন, পুরো কোড কপি করে এডিটরে পেস্ট করুন।
5. প্রথম দিকের এই লাইনে নিজের একটা গোপন PIN দিন:
   ```js
   const APP_PIN = 'baby1234';
   ```
   যেমন `const APP_PIN = 'dukkan2580';`। এই PIN কাউকে দেবেন না।
6. সেভ করুন (Ctrl+S বা ডিস্কের আইকন)।

### ধাপ ২: অনুমতি দিন

1. এডিটরের উপরে ফাংশনের লিস্ট থেকে **testSetup** বাছুন, তারপর **Run** চাপুন।
2. "Authorization required" এলে **Review permissions** চাপুন, নিজের Google অ্যাকাউন্ট বাছুন।
3. "Google hasn't verified this app" দেখালে **Advanced > Go to ... (unsafe)** চাপুন, তারপর **Allow**। (কোডটা আপনার নিজের, তাই এটা নিরাপদ।)

### ধাপ ৩: Deploy করুন

1. উপরে ডানে **Deploy > New deployment**।
2. বাম পাশের গিয়ার আইকনে চেপে **Web app** বাছুন।
3. **Execute as:** Me, **Who has access:** Anyone।
4. **Deploy** চাপুন। যে **Web app URL** আসবে (শেষে `/exec`) সেটা কপি করুন।

### ধাপ ৪: অ্যাপে যুক্ত করুন

1. ফোনে অ্যাপ খুলুন: https://gonialsayed.github.io/baby-dukkan/
2. Web app URL আর PIN দিয়ে **যুক্ত করুন** চাপুন। ব্যস!
3. ফোনের Chrome-এ মেনু (⋮) থেকে **Add to Home screen** দিলে অ্যাপের মতো আইকন বসে যাবে।

> কোড পরে আপডেট করলে **Deploy > Manage deployments > Edit (পেন্সিল) > Version: New version > Deploy** দিন, তাহলে URL একই থাকবে।

## ডাটা ও নিরাপত্তা

- সব তথ্য শুধু আপনার Google Sheet-এ থাকে। এই GitHub রিপোতে কোনো কাস্টমারের তথ্য নেই।
- অ্যাপ শিটে ঢুকতে PIN লাগে। Web app URL আর PIN একসাথে কাউকে দেবেন না।
- অ্যাপ দিয়ে কোনো কিছু মুছে ফেলা যায় না। ভুল হলে শিটে গিয়ে ঠিক করুন, অথবা **File > Version history** থেকে আগের অবস্থা ফেরত আনুন।
- অ্যাপ দিয়ে অর্ডার নিলে প্রোডাক্টের দাম ওই অর্ডারে স্থায়ীভাবে লেখা থাকে। পরে দাম বদলালেও পুরনো অর্ডারের হিসাব বদলায় না।

## শিটের সাথে কীভাবে মেলে

| অ্যাপে | শিটে |
|---|---|
| নতুন অর্ডার | Orders + Order Items (নতুন কাস্টমার হলে Customers-ও) |
| স্ট্যাটাস আপডেট | Orders-এর Status, Courier, Courier + COD Cost, Tracking ID |
| কাস্টমার | Customers |
| প্রোডাক্ট | Products |
| মাল কেনা | Stock In |
| খরচ | Expenses |

শিটের Dashboard আর Profit Calculator আগের মতোই কাজ করবে। Settings ট্যাবে Courier, Category ইত্যাদির লিস্ট বদলালে অ্যাপে রিফ্রেশ চাপুন।

## ফাইল

- `index.html`, `style.css`, `app.js`: ওয়েব অ্যাপ (কোনো বিল্ড লাগে না)
- `apps-script/Code.gs`: Google Sheet-এর জন্য কোড
- `manifest.webmanifest`, `icon-*.png`: হোম স্ক্রিন আইকন
